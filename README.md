# Chest Memory (Fabric 26.1.2 / 26.2)

Клиентский мод: память сундуков **по каждому миру и серверу**, панель **Ё**, подсветка, **Jade**, сбор для **Litematica**.

## Возможности

### Память
- Сундуки, бочки, шалкеры, воронки, раздатчики, эндер-сундук, шалкеры в инвентаре
- **Двойной сундук = 1 контейнер** (обе половины → один ключ)
- **Отдельный файл на каждый одиночный мир и каждый сервер** (`host:port`)
- Данные разных серверов **не смешиваются**

### Панель Ё
- **Вкладка мира/сервера** — переключайся и смотри, что есть в других профилях
- ★ = текущий мир (LIVE); остальные — только просмотр
- Поиск, фильтр, количество справа
- Экспорт CSV

### Подсветка
- 20 секунд, полный блок (двойной — оба блока)
- Подсветка слотов в GUI
- Waypoints

### Jade (опционально)
- При наведении на контейнер сверху: **всего предметов**, число видов, иконки с количеством
- Если ещё не открывали: «ещё не сканировали»

## Установка

1. Minecraft **26.1.2** или **26.2** + Fabric Loader + Fabric API  
2. (по желанию) **Jade**, **Litematica** под ту же версию игры  
3. `build/libs/chestmemory-1.0.0.jar` → `mods`  

Один jar подходит для **26.1.2** и **26.2**.

```powershell

```
